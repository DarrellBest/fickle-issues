# Fickle bug reports and feedback

This repository is for bug reports and feedback for [Fickle](https://darrellbest.com/games/fickle/). It has no source code.

## How to file a good report

Open a [new issue](https://github.com/DarrellBest/fickle-issues/issues/new/choose) and pick the form that fits. Please include:

- The game version
- Your operating system (Windows, macOS, Linux, or Steam Deck)
- The steps that led to the problem
- What you expected, and what actually happened
- Logs and screenshots, if you have them

If you have log files, paste the relevant lines into the form. You do not need to know an exact folder path; copy what you can from the game or from a crash dialog. Do not include passwords, Steam Guard codes, or payment details.
